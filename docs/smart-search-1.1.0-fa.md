- آخرین نسخهٔ رسمی مشاهده‌شده در GitHub: v0.1.136، انتشار 2026-10-31T23:27:12Z. این هسته نصب نشده است.

## مسیر جدید

```text
مهارت مرجع search-tool-routing
  → release/bin/smart-search
  → قفل اجرای ترتیبی برای محدودکردن فشار روی VPS
  → Python 3.12 مستقل
  → SearXNG + Exa + Tavily در صورت وجود کلید
  → برای پرسش علمی: Semantic Scholar + PubMed
  → DDGS برای نتایج کم یا درخواست منطقه‌ای/خبری
  → حذف تکرار URL و RRF
  → FlashRank برای انگلیسی؛ واژگان نرمال‌شده + RRF برای فارسی
  → حداکثر دو نتیجه از هر hostname
  → خروجی JSON شامل وضعیت منابع و زمان اجرا
```

## تغییرات انجام‌شده

1. SearXNG محلی با Gunicorn و سرویس کاربری مستقل راه افتاد؛ فقط 127.0.0.1:8888، یک worker و سقف RAM برابر 384MB، سقف CPU برابر 50 درصد. رمز سرویس در فایل خصوصی است و در این گزارش نیست.
2. Python 3.12 مستقل با httpx، python-dotenv، youtube-transcript-api، yt-dlp، DDGS، Groq SDK، FlashRank و trafilatura نصب شد؛ وابستگی‌های پایتون سیستم تغییر نکردند. فایل‌های lock برای بازتولید موجودند.
3. مهارت مرجع یکی شد؛ مهارت قدیمی برای سازگاری باقی مانده اما پیش‌فرض غیرفعال است. حتی اگر بات قبلاً آن را انتخاب کرده باشد، دستورهایش به همان اجرایی‌های صحیح اشاره می‌کنند، نه پایتون سیستم.
4. خروجی sources وضعیت موفق، غیرفعال، خطای HTTP و تعداد نتایج را نشان می‌دهد. حالت empty_or_unparsed صادقانه یعنی منبع نتیجه‌ای قابل پردازش نداده؛ اثبات نبودن موضوع نیست.
5. Exa علاوه بر objective، هر دو قالب Text و Highlights را می‌پذیرد. ایراد regex حریص که چند نتیجه را به یک نتیجه کاهش می‌داد اصلاح شد.
6. DDGS fallback محدود به زمان اضافه شد؛ گزینه‌های --region au-en و --kind news اضافه شدند.
7. کش جست‌وجو پنج دقیقه و --fresh برای عبور از آن اضافه شد. کش صفحه یک ساعت و زیرنویس ۲۴ ساعت است. فایل‌های JSON کش به‌صورت اتمیک و خصوصی نوشته می‌شوند؛ حداکثر ۱۰۰۰ فایل نگه داشته می‌شود.
8. خواندن صفحه: Markdown همان مسیر، استخراج محلی trafilatura، سپس Jina و در نهایت مرورگر خود برنامه. دیگر llms.txt جای صفحهٔ مشخص برگردانده نمی‌شود.
9. اصلاح URLهای مستقیم .md، فساد کش، کوتاه‌شدن دائمی کش بر اثر --max-chars و پاسخ‌های فشردهٔ HTTP انجام شد.
10. آدرس‌های خصوصی، credential در URL، پورت‌های غیر ۸۰/۴۴۳ و تغییرمسیر به شبکهٔ داخلی رد می‌شوند. DNS پیش از اتصال بررسی و IP اتصال pin می‌شود؛ پاسخ صفحه سقف ۴MiB دارد. endpointهای جست‌وجو نیز بررسی می‌شوند؛ تنها استثنای داخلی، GET /search روی SearXNG ثابت محلی است. پراکسی محیط برای درخواست‌های HTTP این روتر خاموش است.
11. کتابخانهٔ زیرنویس با API نصب‌شدهٔ 1.2.4 هماهنگ شد؛ yt-dlp برای جست‌وجو و زیرنویس جایگزین نصب شد. Groq SDK آماده است اما بدون کلید غیرفعال است.
12. ابزار خصوصی دریافت کلید بدون نمایش آن آماده شد. کلید به محض فراخوانی بعدی ابزار خوانده می‌شود؛ راه‌اندازی مجدد برنامه لازم نیست.

## شواهد بررسی

- ۱۰ بررسی ایزولهٔ خودکار موفق: رد آدرس خصوصی و credential، pin کردن DNS، رد redirect داخلی، سقف حجم، پاسخ gzip، جلوگیری از جایگزینی llms.txt، حفظ طول کش، fallback و تنوع دامنه، کش جست‌وجو، جلوگیری از endpoint داخلی، dedup، parser چندنتیجه‌ای Exa و سازگاری API زیرنویس (برخی در یک بررسی ترکیب شده‌اند).
- فراخوانی واقعی از اجرایی نصب‌شده: Exa شش نتیجه و SearXNG ده نتیجه؛ پنج نتیجهٔ نهایی؛ FlashRank وضعیت موفق.
- بررسی فارسی/خبر: ۲۴ کاندیدای یکتا، پنج نتیجهٔ نهایی، SearXNG + Exa + DDGS و رتبه‌بندی فارسی موفق.
- بررسی علمی: PubMed پنج نتیجه داد؛ Semantic Scholar با HTTP 429 محدود شد و خطایش در خروجی ثبت شد. بقیهٔ منابع مسیر را ادامه دادند.
- خواندن واقعی https://www.python.org/doc/ با local_trafilatura و ۸۱۰ نویسه؛ مسیر Jina هم برای صفحهٔ about نتیجه داده است.
- پس از راه‌اندازی مجدد در حالت بدون بات مشغول: health پاسخ داد و ۱۳ بات، ۷ گروه، شناسهٔ تردها و مدل‌ها پیش و پس از تعویض برابر بودند. هیچ پیام آزمایشی به چت‌های کاربر فرستاده نشد.

## محدودیت‌ها؛ ادعای موفقیت کامل نداریم

- یوتیوب IP دیتاسنتر را با RequestBlocked رد کرد؛ مسیر yt-dlp نیز در فراخوانی واقعی زیرنویس نداد. خروجی no_transcript است. نصب ابزار یا داشتن کلید Groq تضمین نمی‌کند صوت از یوتیوب قابل دریافت شود؛ می‌توان فایل صوتی/ویدیویی مجاز را جداگانه در اختیار ابزار گذاشت یا از مرورگر شخصی استفاده کرد. دورزدن محدودیت یا دسترسی به حساب انجام نشده است.
- Semantic Scholar بدون کلید گاهی 429 می‌دهد. کلید اختیاری می‌تواند کمک کند ولی محدودیت را تضمیناً حذف نمی‌کند.
- Crawl4AI عمداً نصب/فعال نشد: مرورگر بدون ایزولاسیون egress می‌تواند حفاظت SSRF روتر را دور بزند و روی VPS هم سنگین است. استخراج محلی سبک + مرورگر موجود جایگزین شد؛ هیچ مرورگر دوم نصب نشده است.
- Context7 فقط اگر واقعاً روی بات mount شده باشد استفاده می‌شود؛ این انتشار ادعای نصب Context7 ندارد.
- اخبار در Exa همچنان جست‌وجوی عمومی است؛ حالت news مشخصاً به SearXNG، DDGS و Tavily در صورت کلید اعمال می‌شود. تاریخ و تازگی را باید با منبع اصلی تطبیق داد.
- حفاظت این روتر، جایگزین ایزولاسیون امنیتی کل برنامه نیست. Jina و موتورهای بیرونی سرویس ثالثند؛ اطلاعات محرمانه نباید به آن‌ها داده شود.
- آزمون Groq و Tavily با کلید واقعی ممکن نبود چون کلید موجود نیست؛ هزینه‌ای ایجاد نشده است.

## کلیدها: کجا بگیری و چطور ثبت کنی

### Tavily — اولویت اول، اختیاری

- https://app.tavily.com
- ثبت‌نام و ساخت API Key؛ طبق مستندات مشاهده‌شده پلن شروع رایگان دارد، اما سهمیه و قیمت را همان روز از داشبورد بررسی کن. کارت/پلن پولی لازم نیست خودکار فعال شود.
- کاربرد: منبع دوم تجاری مستقل برای وب و خبر؛ جست‌وجو بدون آن هم اکنون کار می‌کند.

```bash
python3 /home/ubuntu/projects/openmausbot-smart-release-20261031/release/scripts/omb-search-keys.py TAVILY_API_KEY
```

### Groq — برای تبدیل صوت به متن، اختیاری

- https://console.groq.com/keys
- ثبت‌نام و Create API Key؛ محدودیت مصرف را در داشبورد تنظیم کن. مدل هدف whisper-large-v3-turbo است.
- کلید Groq مشکل مسدودی دانلود یوتیوب را به‌تنهایی حل نمی‌کند.

```bash
python3 /home/ubuntu/projects/openmausbot-smart-release-20261031/release/scripts/omb-search-keys.py GROQ_API_KEY
```

### Semantic Scholar — اختیاری برای پژوهش

- https://www.semanticscholar.org/product/api#api-key
- Request an API Key؛ ممکن است نیاز به شرح کاربرد و تأیید داشته باشد.

```bash
python3 /home/ubuntu/projects/openmausbot-smart-release-20261031/release/scripts/omb-search-keys.py SEMANTIC_SCHOLAR_API_KEY
```

Exa عمومی، SearXNG محلی، DDGS، PubMed، FlashRank و استخراج محلی برای این تنظیمات کلید نمی‌خواهند. Google CSE برای حساب تازه پیشنهاد نمی‌شود؛ مسیر قدیمی فقط برای حساب‌های موجود با GOOGLE_CSE_API_KEY و GOOGLE_CSE_CX باقی مانده و بررسی نشده است.

مقدار کلید را در چت نفرست؛ فقط در پرامپت مخفی ترمینال وارد کن. فایل مقصد ~/.config/omb-search/.env با مجوز 0600 است. این فایل در آرشیو سورس قرار نمی‌گیرد.

## آخرین نسخهٔ رسمی 0.1.136 چه دارد؟

بر اساس release notes رسمی، نه آزمایش محلی:

- اشتراک‌گذاری دسترسی بات به‌صورت بات‌به‌بات در Team mode؛ درخواست دسترسی برای اعضای بدون دسترسی.
- زبان‌بندی بیشتر اعلان اجرا و روتین، اتصال، اتاق، تحویل کار و نتیجهٔ هم‌تیمی‌ها.
- خلاصه‌سازی گفتگوهای طولانی هنگام بیکاری برای پاسخ اول سریع‌تر.
- پیگیری گزارش با @devs و اطلاع یک‌بارهٔ رفع مشکل.
- بهترشدن حضور بات‌ها در چند محل (سرور، کامپیوتر و Cloud).
- قاب/نوار عنوان تازه و تنظیم Window frame برای برگشت به ظاهر کلاسیک.
- تبدیل سایدبار به آواتار با کشیدن لبه؛ حذف دکمهٔ collapse و تنظیم density قبلی.
- رفتار مستقیم‌تر Just do it، معطل‌نشدن پیام کاربر پشت ابزار طولانی، اصلاح نشانگر unread و کارت‌های کنار rail.
- اصلاح تنظیمات Claude هر ترد و پوشهٔ کاری بات، سؤال و follow-up هم‌تیمی‌ها، نصب/ورود Kimi، منوی Settings سرور دوردست، اتاق‌ها و انتظار برای ابزار، صفحات pinned، رایانهٔ قرض‌داده‌شده و مدل‌های Cursor.
- به‌روزرسانی امنیتی better-auth به 1.7.7 و happy-dom به 21.0.4 در changelog ذکر شده است.

این مواردِ هستهٔ 0.1.136 به برنامهٔ فعلی اضافه نشده‌اند. به‌خصوص حذف density و تغییر ساختار سایدبار با پچ‌های سفارشی فعلی تداخل بالقوه دارد؛ برای ارتقای هسته باید مرحلهٔ جداگانهٔ انتقال پچ، بیلد، fixture و cutover انجام شود. 1.1.0 شمارهٔ موتور جست‌وجو است، نه ادعای ارتقای هسته به 0.1.136.
